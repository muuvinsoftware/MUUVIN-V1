# MUUVIN V1 — 1.6.12

## 🔊 Even, louder factory presets

Every preset in the **MUUVIN Analog Dreams** factory bank was rendered, measured and **loudness-matched to a single target (−11 dBFS)** — that's **+3 dB louder** than before — with a **−2 dBFS peak ceiling** so nothing clips.

- Presets that used to be too quiet are brought up.
- Switching patches no longer means reaching for the volume knob every time.
- Your own presets and imported banks are left untouched.

The updated bank is applied automatically the next time you open the plugin.

## 📜 Scrollable EFFECTS · A–Z list

With the FX rack now holding **23 effects**, the alphabetical list on the FX page would run off the bottom. It now **scrolls** — use the mouse wheel over the column or the slim scrollbar on the right — so the last effects are no longer cut off. The **SAT / PAN / FX MIX / OUTPUT / ORDER / SYNC / BYPASS** controls stay pinned at the bottom of the column.

**Platform:** Windows (VST3, 64-bit).
**Install:** run `MUUVIN V1 Installer.exe` (or unzip the "VST3 plugin only" archive into your VST3 folder). Close your DAW before installing.
